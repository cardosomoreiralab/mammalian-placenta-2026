# A division of labour underlies a cell type expansion in the placenta

Code and processed data for Falis et al. 2027 ([journal], [DOI]).

## Content

In this repository, you can find the code necessary to reproduce figures presented in our study. The data processing steps are described in the Methods section of the study.

All scripts below start from processed objects and reference files deposited in this repository (see Data availability). Non-processed (raw) files have been deposited to ArrayExpress (see Data availability).

## Reference data

Files necessary to replicate the analysis (such as gene lists, orthology tables, etc.) can be found in folder Reference_files.

## Data availability

* Single-nucleus RNA-seq: ArrayExpress 
* Single-nucleus ATAC-seq: ArrayExpress 
* Annotated Seurat objects for all six atlases, the ArchR project and the
  SCENIC+ output are deposited alongside the raw data
