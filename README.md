# A division of labour underlies a cell type expansion in the placenta

Code and processed data for Falis et al. 2027 ([journal], [DOI]).

*Trophoblasts are a diverse group of placental cells that perform essential functions during mammalian pregnancy. Mice have twice as many trophoblast cell types as humans, but how and why this difference evolved is unknown. By comparing ~375,000 single-nucleus transcriptomes across primates, rodents and lagomorphs, we show that it stems from a cell type expansion that doubled the number of trophoblast cell types in murid rodents. Our results indicate the new cell types evolved through a division of labour, specialising in functions that, in the other species, are performed by a single, multifunctional syncytiotrophoblast. Reconstruction of the gene regulatory networks of the new cell types indicates they evolved by modifying a shared pan-trophoblast regulatory network, either by acquiring new cell-type-specific regulons or by partitioning an ancestral network between two cell types. Our work explains why the mouse and human placenta differ in cellular composition and reveals how new cell types can originate and acquire their functions.*


## Content

In this repository, you can find the code necessary to reproduce figures presented in our study. The data processing steps are described in the Methods section of the study.

All scripts below start from processed objects and reference files deposited in this repository (see Data availability). Non-processed (raw) files have been deposited to ArrayExpress (see Data availability).

## Reference data

Files necessary to replicate the analysis (such as gene lists, orthology tables, etc.) can be found in folder Reference_files.

## Data availability

* Single-nucleus RNA-seq: ArrayExpress 
* Single-nucleus ATAC-seq: ArrayExpress 
* Annotated Seurat objects for all six atlases, the ArchR project and the
  SCENIC+ output are deposited alongside the raw data
